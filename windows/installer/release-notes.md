Right-click a file in File Explorer, pick a format, done. Everything is converted on your own PC.

**Install:** download `Convert-…-setup.exe` below and run it. Windows 11, 64-bit. If Windows says
"Windows protected your PC", click **More info → Run anyway**: this release isn't code-signed yet.
`.sha256` is the file's SHA-256 fingerprint, to check the download.

### What's in this version

- **Convert to ▸** in the right-click menu: a few common formats per kind of file (MP3, MP4, GIF, JPEG, PNG,
  PDF, …) that convert at once with your saved settings; the window closes by itself when it's done.
- **Convert…** opens the window with every format and the settings; **Send to → Convert** works too.
  Several selected files arrive in one window.
- **Save to:** next to the original, a folder you choose, or ask every time.
- **Open when done**, and on the desktop the new file's icon goes right below the original's.
- **ffmpeg is included**: audio and video work without installing anything else.

Based on [Convert](https://github.com/newtonstudios/convert) 0.4 by Elias de Sena and contributors.
